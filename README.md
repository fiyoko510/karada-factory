# からだの工場

食べたものがエネルギーに変わるまでと、入ってきたものが体から出ていくまで。
経路図をたどりながら、実際の生化学の収支で遊べるブラウザゲームです。

**▶ https://fiyoko510.github.io/karada-factory/**

インストール不要。スマホでも動きます。

---

## 収録

### 01. ミトコンドリア厨房
一食ぶんの献立を組むと、そこから取り出せるATPが計算されます。
カロリーが高いほど高得点、ではありません。糖質や脂質を分解する各工程には
ビタミンB群・鉄・マグネシウムが道具として必要で、足りないと経路が細くなります。

白ごはん＋卵＋納豆と、玄米＋卵＋納豆。潜在ATPはほぼ同じなのに、
ビタミンB1の充足率の差でスコアが大きく変わります。

### 02. 肝臓の解毒工場
コーヒーも、薬も、お酒も、保存料も、そして自分の体が作ったホルモンや老廃物も、
肝臓ではまったく同じ1本のラインで処理されています。

第1相（CYP450による酸化）→ 反応性中間体 → 第2相（抱合）→ 第3相（排出）を
たどっていくと、何が本当に負担なのかが数字で見えます。

### 03. 用語図鑑
解糖系はどこで起きているのか。パントテン酸とは何か。
体の地図、経路ごとの反応式、栄養素のキャラクター、ミニ用語辞典。
ゲーム中の用語をタップしても、同じ解説が開きます。

## 遊びかた

1. 場面を選ぶ（朝ごはん / 駅までダッシュ / 飲み会の夜 …）
2. 枠のなかで食材を選んで、献立を組む
3. 「代謝スタート」。経路図を粒が流れていく。詰まっているところは粒が小さく、遅くなる
4. 結果を見て、1品だけ入れ替えて、もう一度

## 数値について

学習用に簡略化したモデルです。ただし、比率は実際の生化学に沿わせています。

- ATPの収支はグルコース1分子あたり約30〜32ATPを基準にしています（一般的な推定値で、細胞や条件によって変わります）
- 食品添加物の負荷は、認可された添加物の実際の摂取量に近い比率で扱っています
- 栄養素の必要量は日本人の食事摂取基準を参考にした概算です
